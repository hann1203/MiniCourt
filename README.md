# MiniCourt ⚖️
*A courtroom workflow companion for navigators, deputies, and legal staff.*

MiniCourt is a desktop application designed to streamline courtroom workflow, improve hearing documentation, and support legal professionals with a clean, modern, courtroom‑inspired interface.  
Built with Python and Tkinter, MiniCourt brings together docket management, event logging, judge profiles, journaling, and data exports — all in one cohesive tool.

---

## Features

- **Courtroom Event Logger**  
  Log hearing events in real time with structured categories, timestamps, and notes.

- **Docket Import & Management**  
  Import CSV docket files, track which entries have been used, and prepare your day efficiently.

- **Judge Profiles**  
  Store quick‑reference notes, preferences, and courtroom behaviors for each judge.

- **Journal & Reflection Tools**  
  Capture daily reflections, insights, and personal notes with a clean journaling interface.

- **Data Center**  
  View summaries, export hearing data, and analyze trends across cases.

- **Export Options**  
  Export hearings to TXT, PDF, and CSV formats.

- **Cute‑Courtroom Aesthetic**  
  A warm, readable UI with a professional yet charming courtroom vibe.
